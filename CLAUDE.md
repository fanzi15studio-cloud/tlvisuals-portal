# TLVisuals Portal — Contexte projet

## Stack technique
- **Framework** : Next.js 14 (App Router)
- **Language** : JavaScript (React)
- **Repo GitHub** : fanzi15studio-cloud/tlvisuals-portal
- **Branche de dev** : `claude/centralize-mac-project-Wd0ek`

## Structure du projet
```
tlvisuals-portal/
├── app/                   # Application Next.js
├── tlvisuals-site/        # Site HTML statique
├── site-internet.md/      # Assets du site (img, CSS)
├── developer/             # Documentation développeur
├── next.config.mjs
└── package.json
```

## Commandes terminal usuelles

```bash
# Lancer le serveur de développement
npm run dev

# Builder pour la prod
npm run build

# Lancer en prod
npm start

# Installer les dépendances
npm install

# Git - pousser sur la branche de dev
git push -u origin claude/centralize-mac-project-Wd0ek
```

## Notes importantes
- Ne jamais pousser directement sur `main` sans confirmation
- Toujours développer sur la branche désignée ci-dessus
- Le projet est hébergé / géré via GitHub : fanzi15studio-cloud/tlvisuals-portal
