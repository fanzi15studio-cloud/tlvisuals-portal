# Aeterna Labs — Guide informatif sur les peptides

Dossier de travail pour le **guide informatif et éducatif** sur le rôle des peptides
dans le corps humain, destiné à être distribué par le client **Aeterna Labs**.

## Règles du projet (importantes)

- **Objectif** : document purement **informatif et éducatif**.
- **Interdit** : aucun **prix**, aucune mention de **revendeur / vente / commande**.
- **Ton** : scientifique, pédagogique, premium. Pas de conseil médical, pas de protocole
  de dosage / d'administration. Mentions de prudence et renvoi vers un professionnel de santé.
- **Langue** : français.
- **Identité visuelle** : couleurs d'Aeterna Labs (à fournir — voir `brand/`).

## Organisation du dossier

| Dossier | Contenu |
|---|---|
| `brand/` | Logo Aeterna Labs, codes couleurs, polices. **À déposer ici.** |
| `sources/` | Documents sources (PDF de la World Peptide Association + texte extrait). |
| `inspiration/` | Captures d'écran / références de design à déposer + notes de direction artistique. |
| `livraison/` | Exports finaux du guide (PDF, etc.). |

Le **livrable web** est publié sous `public/aeterna-guide-peptides/` (convention du portail).
