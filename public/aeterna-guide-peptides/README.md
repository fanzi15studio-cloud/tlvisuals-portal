# Guide Aeterna Labs — Les Peptides & le corps humain

Guide **informatif et éducatif** (FR) sur le rôle des peptides dans le corps humain,
aux couleurs d'Aeterna Labs. Document non commercial : **aucun prix, aucun revendeur,
aucun protocole de dosage**.

## Consulter

- **En ligne** (portail déployé) : `/aeterna-guide-peptides/`
- **En local** : ouvrir `index.html` dans un navigateur.

## Exporter en PDF (A4)

Bouton **« Télécharger en PDF »** en haut de page → *Enregistrer en PDF*
(activer « Graphiques d'arrière-plan » / *Background graphics*).
Un export déjà généré est disponible dans `clients/aeterna-labs/livraison/`.

## Technique

- HTML autonome, polices Google (Cormorant Garamond + Montserrat).
- Illustrations en SVG vectoriel (net à l'impression), palette de marque en variables CSS.
- 14 pages A4 · mise en page écran + impression.
